# Chapter 1

This is the chapter 1 release of the compiler based on *Writing a C
Compiler* by Nora Sandler.

It accepts one `int` function with `void` parameters and a
single `return` statement containing a positive integer literal.

## Download

| Host | Archive |
| --- | --- |
| Apple Silicon Mac | `compiler-0.1.0-osx-arm64.tar.gz` |
| Linux x86-64 (built on Ubuntu 24.04) | `compiler-0.1.0-linux-x64.tar.gz` |

The native compiler runs without .NET. Put `gcc` on `PATH` to preprocess,
assemble, and link C programs. On macOS, the `gcc` provided by Apple's Command
Line Tools works. Both builds generate x86-64 programs. Apple Silicon requires
Rosetta 2 to run the generated programs.

## Verify the download

Use the GitHub CLI to verify the build provenance of the archive you downloaded.

```sh
gh attestation verify compiler-0.1.0-osx-arm64.tar.gz --repo zachdillard/Compiler
gh attestation verify compiler-0.1.0-linux-x64.tar.gz --repo zachdillard/Compiler
```

## Try it

Extract the archive, open a terminal in the extracted directory, and save this
as `return_int.c`.

```c
int main(void) {
    return 2;
}
```

```sh
./Compiler --version
# Compiler 0.1.0
./Compiler return_int.c
./return_int
echo $?
# 2
```

Use at most one of these flags per invocation.

| Flag | Behavior |
| --- | --- |
| `--lex` | Stop after lexing. |
| `--parse` | Stop after parsing. |
| `--codegen` | Stop after code generation. |
| `-S` | Emit assembly without linking. |
