# Chapter 1 alpha

An initial testing prerelease of the chapter 1 compiler from *Writing a C
Compiler* by Nora Sandler. Version `0.1.0` is reserved for the stable chapter 1
release.

Supports a single `int` function with `void` parameters returning an integer
constant, plus `--lex`, `--parse`, `--codegen`, and assembly-only `-S` modes.
Later chapters and extra credit are not implemented.

Download and extract the archive for your host:

- `compiler-0.0.1-alpha-osx-arm64.tar.gz`: Apple Silicon, macOS 27.
- `compiler-0.0.1-alpha-linux-x64.tar.gz`: Linux x86-64, built on Ubuntu 26.04;
  requires compatible system libraries.

Each archive includes `Compiler`, `README.md`, and `LICENSE`. The native compiler
runs without .NET installed. GCC must be on `PATH` for preprocessing, assembly,
and linking. Both targets generate x86-64 programs; Apple Silicon requires
Rosetta 2 to run generated programs.

For example, after extracting the macOS archive:

```sh
./compiler-0.0.1-alpha-osx-arm64/Compiler --version
# Compiler 0.0.1-alpha
./compiler-0.0.1-alpha-osx-arm64/Compiler program.c
./program
echo $?
```

Use the corresponding Linux directory on Linux. A source build requires the
pinned .NET 11 RC1 SDK, `11.0.100-rc.1.26425.128`.
